Basic R Commands

Throughout this guide we use a simple dataset containing GDP (in billions of USD) and year for a hypothetical country from 1980 to 2023. All examples build on this dataset.

1. Creating the Dataset

We start by constructing the dataset directly in R.

CommandDescription
year <- 1980:2023Create a vector of years from 1980 to 2023
gdp <- c(2.8, 3.1, 3.0, 3.4, 3.7, 4.0, 4.3, 4.7, 5.1, 5.5,
5.9, 6.2, 6.5, 6.9, 7.3, 7.7, 8.1, 8.4, 8.7, 8.9,
9.2, 9.6, 10.1, 10.5, 10.9, 11.3, 11.8, 12.2, 12.5, 12.1,
12.8, 13.3, 13.9, 14.5, 14.2, 14.8, 15.3, 15.9, 16.4, 16.9,
17.4, 17.9, 18.5, 19.1)		Create a vector of GDP values (one per year)
df <- data.frame(year = year, gdp = gdp)Combine into a data frame

2. Inspecting the Data

Before analysing data it is good practice to inspect its structure and contents.

CommandDescription
head(df)Show the first 6 rows of the data frame
tail(df)Show the last 6 rows
str(df)Show variable types and a preview of values
dim(df)Number of rows and columns (44 rows, 2 columns)
nrow(df)Number of rows (44)
ncol(df)Number of columns (2)
names(df)Column names: "year" and "gdp"

3. Accessing Variables

There are several ways to access columns or specific values.

CommandDescription
df$gdpExtract the gdp column as a vector
df$yearExtract the year column
df[1, ]First row (year 1980)
df[, 2]Second column (gdp)
df[1, 2]GDP in 1980 (first row, second column)
df$gdp[1]GDP in 1980 (first element of gdp vector)

4. Summary Statistics

Compute basic statistics on GDP across all years.

CommandDescription
summary(df)Summary statistics for all columns
mean(df$gdp)Average GDP across all years
median(df$gdp)Median GDP
sd(df$gdp)Standard deviation of GDP
var(df$gdp)Variance of GDP
min(df$gdp)Lowest GDP value (1980)
max(df$gdp)Highest GDP value (2023)
range(df$gdp)Min and max together
quantile(df$gdp, 0.25)25th percentile of GDP
sum(df$gdp)Total GDP summed across all years

5. Creating New Variables

We can create new columns derived from existing ones.

CommandDescription
df$gdp_log <- log(df$gdp)Log of GDP
df$gdp_growth <- c(NA, diff(df$gdp) / df$gdp[-nrow(df)] * 100)Year-on-year GDP growth rate (%)
df$decade <- floor(df$year / 10) * 10Decade each year belongs to
df$post2000 <- as.integer(df$year >= 2000)Dummy variable equal to 1 from year 2000 onward

6. Subsetting the Data

Select specific rows based on conditions.

CommandDescription
df[df$year >= 2000, ]Rows from year 2000 onward
subset(df, year >= 2000)Same result using subset()
subset(df, year >= 1990 & year <= 1999)Only the 1990s
subset(df, gdp > 15)Years where GDP exceeded 15 billion
df[df$year == 2008, ]Data for the year 2008

7. Sorting and Ordering

CommandDescription
df[order(df$gdp), ]Sort rows by GDP ascending
df[order(-df$gdp), ]Sort rows by GDP descending
which.max(df$gdp)Row index of the highest GDP
which.min(df$gdp)Row index of the lowest GDP
df$year[which.max(df$gdp)]Year with the highest GDP

8. Missing Values

GDP growth in the first year is NA because there is no previous year to compare with.

CommandDescription
is.na(df$gdp_growth)Identify missing values (TRUE/FALSE for each row)
sum(is.na(df$gdp_growth))Count of missing values (1, for 1980)
mean(df$gdp_growth, na.rm=TRUE)Mean growth rate ignoring the missing value
na.omit(df)Remove all rows containing any missing value

9. Reading and Writing Data

In practice you will load data from a file rather than typing it in manually.

CommandDescription
df <- read.csv("gdp_data.csv")Load data from a CSV file
write.csv(df, "gdp_data.csv", row.names=FALSE)Save data frame to a CSV file
saveRDS(df, "gdp_data.rds")Save as an R object file
df <- readRDS("gdp_data.rds")Load an R object file

10. Plotting

Visualise the relationship between year and GDP.

CommandDescription
plot(df$year, df$gdp, type="l")Line plot of GDP over time
plot(df$year, df$gdp, type="l",
main="GDP over Time",
xlab="Year", ylab="GDP (billions USD)")		Line plot with title and axis labels
hist(df$gdp_growth, main="GDP Growth Rate",
xlab="Growth (%)")		Histogram of annual growth rates
boxplot(df$gdp_growth,
main="Distribution of GDP Growth")		Box plot of growth rates
abline(v=2008, col="red", lty=2)Add a vertical dashed line at 2008 (financial crisis)

11. Conditional Logic with ifelse()

ifelse() applies a condition to every row and returns one value if TRUE and another if FALSE. This is useful for creating new variables based on conditions.

CommandDescription
df$high_gdp <- ifelse(df$gdp > 10, "High", "Low")Label years as "High" or "Low" GDP (threshold: 10 billion)
df$recession <- ifelse(df$gdp_growth < 0, 1, 0)Dummy equal to 1 in years where GDP shrank
df$era <- ifelse(df$year < 2000, "Pre-2000", "Post-2000")Label each year as pre- or post-2000
df$growth_label <- ifelse(df$gdp_growth > 3, "Fast",
  ifelse(df$gdp_growth > 0, "Slow", "Negative"))		Nested ifelse(): three categories of growth
